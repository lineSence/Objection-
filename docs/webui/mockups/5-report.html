SQLite или PostgreSQL для истории запусков

Вердикт. SQLite за абстракцией хранения; PostgreSQL — опциональный бэкенд для многопользовательского веб-режима.

Обоснование

Для однопользовательского режима SQLite не требует отдельного сервиса и хранится одним файлом рядом с конфигом. WAL-режим позволяет читать во время записи, что закрывает сценарий WebUI + CLI одновременно.

Утверждение, что SQLite вообще не поддерживает конкурентную запись, неверно: допускается один писатель одновременно с читателями. Однако при нескольких воркерах на разных машинах SQLite действительно становится узким местом.
