# Eval Harness (M4)

Отвечает на главный вопрос проекта: **лучше ли совет, чем очевидные альтернативы, на вашем пуле моделей и при том же бюджете?** Пул меняется (D-006), поэтому eval запускается одной командой на текущем составе.

```bash
objection eval run                              # math-mini, пресеты verify и quick
objection eval run --suite code-mini            # задачи с тестами, пресет code
objection eval run --suite mine                 # ваши размеченные запуски
objection eval run --suite gsm8k.jsonl --n 50 --presets verify,deliberate --parallel 4
objection eval list                             # история
objection eval show <id> [--format json]        # отчёт
```

Для платных моделей CLI спрашивает подтверждение (`--yes` — без вопроса). Код выхода: 0 — каждый пресет обошёл все baseline, 1 — нет, 3 — ошибка.

## Что запускается

На каждой задаче:

| Рукав | Что это |
| --- | --- |
| пресет (`verify`, `quick`, `deliberate`, `code`) | полный протокол совета; фактчек выключен (`--check` включает) |
| `single:<модель>` | каждая модель совета одна: один ответ (или одно решение + раунд исправлений для кода) |

Из этого считаются **три baseline при равном бюджете**:

| Baseline | Как |
| --- | --- |
| `best_single` | модель с лучшей одиночной точностью на этом наборе. Выбрана задним числом — это преимущество baseline: если пресет всё равно выигрывает, выигрыш настоящий |
| `self_consistency@k` | k сэмплов лучшей модели (`--sc-temperature`, по умолчанию 0.7), большинство голосов; для кода — «прошло тесты хотя бы одно». **k подбирается под бюджет пресета:** средняя стоимость пресета / стоимость одного ответа; для бесплатных моделей (локальные, mock) — по числу вызовов. k ≤ 9 |
| `vote` | один ответ от каждой модели совета, простое большинство (только задачи с ответом) |

Пресет **обходит baseline**, если его точность строго выше каждого из них. Иначе он помечается, и `auto` для этого совета выбирает другой короткий протокол (`verify` ↔ `quick`), если тот не проиграл, или оставляет режим с предупреждением в `route_reason`. Отключить: `defaults.respect_eval: false`.

## Метрики

- точность, воздержания (`uncertain` / ничья), $ и секунды на задачу, число вызовов;
- переходы правильный → неправильный и обратно после критики (по каждой модели);
- калибровка уверенности совета: Brier score и ECE (5 корзин);
- сохранность правильного меньшинства: итог неверен, но кто-то в совете ответил правильно — осталось ли это в голосах / особом мнении;
- корреляция ошибок: попарный φ одиночных моделей, средний φ̄ и n_eff = k / (1 + (k − 1)·φ̄);
- знаковый тест против лучшей одиночной модели (победы / поражения / p-value). На маленьких наборах выводы предварительные — смотрите p-value.

## Наборы

| Набор | Что |
| --- | --- |
| `math-mini` | 30 текстовых задач в стиле GSM8K, числовые ответы (свои, проверены скриптом) |
| `code-mini` | 8 задач в стиле HumanEval со своими тестами |
| `mine` | ваши запуски `verify` / `quick` / `deliberate` с известным ответом: `--expected` или метка «верно» у `verify`/`quick` |
| файл `.jsonl` / `.json` | `{"question", "expected"}`; GSM8K (`{"question", "answer": "… #### 42"}`); HumanEval (`{"task_id", "prompt", "test", "entry_point"}`); `{"task", "test"}` |

Ответ засчитывается нестрого по форме и строго по значению: `1,116 books` = `1116`, для чисел — последнее число ответа или число в первой строке, для `true/false` — первое слово, для короткого текста — вхождение целым словом.

## Разметка своих запусков

```bash
objection runs label <run_id> correct
objection runs label <run_id> wrong --expected 42    # правильный ответ оценивает каждую модель
objection runs label <run_id> clear
```

В Web UI — кнопки 👍 / 👎 на странице запуска (при 👎 можно указать правильный ответ). Метки сразу пересчитывают статистику по моделям (`model_outcomes`).

## Где лежат результаты

Каждый запуск eval — обычный запуск с `source = eval` и меткой по известному ответу, поэтому он тоже попадает в статистику моделей. В Web UI такие запуски скрыты из списка и «Обзора» (`GET /api/runs?include_eval=true` — показать). Отчёты — таблица `evals` (`GET /api/evals`, `GET /api/evals/{id}`).
