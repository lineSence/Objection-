# Песочница (M3, без Docker)

Используется для тестов режима `code` / `council_solve` и python-проверок Verifier. Docker сознательно не используется (D-015): лишняя зависимость, нет на многих машинах разработчиков и в CI-раннерах без привилегий.

## Что делает

| Мера | Linux | macOS | Windows |
| --- | --- | --- | --- |
| Временная копия проекта, исходная папка не меняется | ✓ | ✓ | ✓ |
| Очищенное окружение: без ключей API и токенов, `HOME`/`TMP` внутри временной папки | ✓ | ✓ | ✓ |
| Таймаут, убийство всей группы процессов | ✓ | ✓ | ✓ (процесс) |
| Лимиты CPU, памяти, размера файлов, без core dump (`setrlimit`) | ✓ | частично (память не всегда) | — |
| Без сети (`unshare -rn`, user namespaces) | ✓ если разрешены user namespaces | — | — |
| Обрезка вывода (`max_output_kb`) | ✓ | ✓ | ✓ |
| Защита от рекурсии: внутри песочницы нельзя запустить совет | ✓ | ✓ | ✓ |

## Чего не делает

**Это не граница безопасности.** Нет изоляции файловой системы: код работает с правами вашего пользователя и может читать ваши файлы. Сеть отключается только там, где это поддерживает ОС. Используйте с доверенными моделями; для потенциально враждебного кода — отдельная VM или контейнер.

## Проверка

```bash
objection sandbox          # что доступно на этой машине + пробный запуск
```

В Web UI — **Настройки → Песочница** (возможности платформы и лимиты).

```yaml
sandbox:
  network: false      # true — разрешить сеть (например, тестам нужен pip)
  timeout_s: 120
  memory_mb: 1024
  cpu_s: 120
  max_output_kb: 256
```
